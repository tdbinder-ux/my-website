# Emberroot Haven – Website Project  
A multi‑page website documenting the development of a year‑round food garden in the Lake Cushman forest.  
This site was created for my Web Development course and includes responsive layouts, a glossary with filtering, a planting schedule table, and a long‑term garden plan.

---

## 🌱 Peer Review Responses (Self‑Assessment)
I did not receive peer feedback on the discussion board, so I completed a self‑review using the guidelines from Chapter 16.  
Below are **two improvement suggestions** I identified for my own site:

### **Suggestion 1: Improve page layout consistency**
Some pages used single‑column layouts while others used multi‑column sections. This made the site feel visually uneven.

### **Suggestion 2: Add more interactive or structured content**
The site had strong text content, but lacked structured elements like tables or interactive components that improve readability and usability.

---

## ✅ Improvements I Made Based on These Suggestions

### **1. Converted multiple pages to two‑column responsive layouts**
- Updated the **Home page** to use a `.two-column` layout for better visual balance.  
- Updated the **Long‑Term Plan page** to use the same two‑column system.  
- Ensures consistency across the site and improves readability on large screens.

### **2. Added structured and interactive content**
- Added a **Seasonal Planting Schedule table** (extra credit requirement).  
- Implemented a **filterable Garden Glossary** using radio buttons + CSS selectors.  
- Added a **Google Font (Lora)** for improved typography.  
- Added **FontAwesome icons** (e.g., seedling icon on the planting schedule page).  
- Added a **favicon** appropriate to the site theme (tree‑of‑life logo).

## 📄 Pages Included in This Project
